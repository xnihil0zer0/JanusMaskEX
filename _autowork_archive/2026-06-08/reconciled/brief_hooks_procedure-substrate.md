# Title

Deterministic procedure substrate: gates, phase reducer, durable state

# Scope

Build the three NEW, pure/stdlib-only, single-file whole-file modules that encode the operator recipe as checked machinery, each over INJECTED seams and never spawning a process or making a model/API/network/SSE/un-injected subprocess call. (1) overseer/gates.py — one pure gate-check function per lesson, each returning a typed GateResult(ok, reason, fix_hint): oracle_is_red(test_path, *, run_seam) asserting the named test FAILS; oracles_committed_at_head(paths, *, git_seam) asserting each oracle path is committed at HEAD not merely on disk; brief_lint(brief_text) checking the brief contains '# Required plan shape', names exactly one target file, has no naked source line-number citations, and is single-file scope; plan_preflight(plan, *, state_dir) WRAPPING (not reimplementing) harness.planner.plan_validator and additionally checking a unique non-'T1' task_id with no state/tasks/processed/<id>.json collision, >=2 edge_cases reflected in regression/property tests, and the literal word 'integration' in non_goals; suite_green_zero_reg(report) asserting the named oracle is GREEN and the full suite shows 0 new regressions vs baseline; posture_locked(*, state_dir) asserting state/control/autowork/full_stop present, state/control/orchestrator.flag==pause, and state/control/autowork/auto_promote.allowlist deny-all. (2) overseer/procedure.py — Phase/Procedure dataclasses, the PROCEDURE_REGISTRY holding the four mode->ordered-phase definitions (brief-author: SCOPE->ORACLE->COMMIT->BRIEF->PLAN->COMPLETE; oracle-author: SCOPE->DRAFT->RED->COMMIT->COMPLETE; dispatch: PREFLIGHT->STAGE->BUILD->VERIFY->RESTORE->COMPLETE; push: SWEEP->ZERO_REG->POSTURE->PUSH->COMPLETE), each phase binding a gate by name plus a single next-action string, and the pure reducer advance(procedure, phase, gate_result) -> Decision returning the next phase, a Blocked(reason, fix_hint), or Complete. (3) overseer/procedure_state.py — durable per-conversation phase pointer plus recorded gate results, read not reconstructed and surviving --resume/restart. Author each module's hand-written RED oracle expectations under tests/overseer/ (test_gates.py, test_procedure.py, test_procedure_state.py) as the per-leaf verification_command targets.

# Non-Goals

No edits to existing overseer symbols (can_switch, dispatch_action, render_mode_context, run_chat_turn) — those belong to the enforcement and runtime children. No new agent spawns, model/API/network/SSE calls, or un-injected subprocesses: all test execution, HEAD membership, and filesystem I/O flow through injected seams (run_seam, git_seam, plain fs reads / state_dir). Do NOT reimplement harness.planner.plan_validator — wrap it. No changes to harness/** or the autowork daemon. No registry entries or procedures for the out-of-scope modes (triage/daemon-supervisor/ui-tester/flag-steward/harness-self-fix/security-review/rebuild-factory) — substrate stays generic so they can adopt a procedure later by adding a registry entry only. This child authors the decomposition's substrate leaves only; it does not dispatch a build or author the production oracles (those are hand-authored and committed before any leaf is dispatched).
