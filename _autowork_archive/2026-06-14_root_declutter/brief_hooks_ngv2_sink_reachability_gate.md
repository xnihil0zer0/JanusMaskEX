# Title

ngv2/sink_reachability_gate.py -- NEW deterministic constant-vs-external sink-argument reachability gate. A NobleGreed finding (`zilliztech/gptcache` command-injection) was marked `verdict=confirmed` because the dangerous sink (a shell/`subprocess` call) executed in isolation -- but in the real code that sink is only ever called with HARDCODED constant arguments, so no attacker input can reach it. "The sink fires" was conflated with "attacker input reaches the sink." This module is the deterministic gate that separates the two: given a sink name and the source snippets of every site that calls it, it AST-parses each call and decides whether ANY argument is externally influenced (not a literal constant). If every argument at every site is a literal constant, the sink is constant-only and the finding MUST NOT be allowed to confirm; if any site passes a Name/attribute/subscript/call/f-string-with-name, the sink is reachable and the finding may confirm. The module is PURE and operates only on the strings passed in (no filesystem, no network, no clock), so it is fully differential-fuzzable.

It operates ONLY on the strings passed in via `call_sites`, which makes it deterministic and differential-fuzzable (identical inputs -> byte-identical output dict).

Primary function: `assess_sink_reachability(sink_name: str, call_sites: list[str]) -> dict`. Each entry of `call_sites` is a Python source snippet that contains at least one call to `sink_name` (bare `sink_name(...)` or dotted `pkg.sink_name(...)`). For each snippet the module AST-parses it (`ast.parse`), walks for `ast.Call` nodes whose callee bare-name or dotted-attribute tail equals `sink_name`, and inspects every positional and keyword argument of those calls. An argument is "external / attacker-influenced" if it is NOT a literal constant -- i.e. it is an `ast.Name`, `ast.Attribute`, `ast.Subscript`, `ast.Call`, an `ast.JoinedStr` (f-string) that embeds a `FormattedValue`/name, or a `.format(...)`/`%`-format expression that embeds a name. An argument is "constant" if it is an `ast.Constant` (str/num/bytes/bool/None), a tuple/list/dict of only constants, or a pure constant string concatenation (`"a" + "b"`, all operands constant). If ANY matched call at ANY site passes at least one non-constant argument, that site source string is appended (in input order, de-duplicated) to `external_input_sites` and the sink is `reachable=True`. If every matched call at every site passes only literal constants (or takes no arguments), `all_constant=True` and `reachable=False`. A snippet that fails to parse, or that contains no call to `sink_name`, contributes no external-input site and does not by itself make the sink reachable.

The returned dict has exactly these keys: `reachable` (bool), `external_input_sites` (list[str]), `all_constant` (bool), `status` (`"reachable"` | `"constant_only"`), `may_confirm` (bool). `status` is `"reachable"` iff `reachable` is True else `"constant_only"`; `may_confirm` equals `reachable`; `all_constant` is the boolean negation of `reachable`.
