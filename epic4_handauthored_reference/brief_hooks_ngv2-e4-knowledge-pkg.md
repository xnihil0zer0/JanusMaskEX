- `ngv2-codebase-graph-extract` -> `ngv2/codebase_graph_extract.py` (gate: pure_fuzz; meta_task_type: data_model (bypass_fuzzer, smoke-gated)). Exposes: GENERATOR_VERSION, EXCLUDE_DIRS, ITEM_FIELDS, NODE_FIELDS, parse_python_file, build_call_graph, emit_module_graph, emit_package_graph, emit_callchain_graph, emit_full_graph, parse_shell_file, walk_repo. Contract: ngv2.codebase_graph_extract is a pure, deterministic, stdlib-only (ast, re, json, pathlib) converter that turns a Python/shell codebase into MASFactory-compatible "vibe graph" JSON — no AI, no network, no code execution; it only reads source text. It exports the constants GENERATOR_VERSION (non-empty str), EXCLUDE_DIRS (a collection that is a superset of {"__pycache__", ".git", ".venv", "node_modules"}), ITEM_FIELDS == ("name","type","source","lineno","calls","imports","parent"), and NODE_FIELDS == ("name","type","instructions","prompt_template"). parse_python_file(file_path)->list[dict]: AST-parses a file and returns one item dict (exactly the ITEM_FIELDS keys) per top-level function (type 'function', parent ''), class (type 'class'), and method (name 'Class.method', type 'method', parent='Class'); 'imports' holds module-level import names (alias or full dotted, e.g. 'os','jd') attached to every item; 'calls' lists called names with dotted attribute chains rendered dotted (e.g. 'os.path.join') and 'self.x' kept literal; lineno is a 1-based int; a missing file or SyntaxError returns [] without raising. build_call_graph(modules: dict[str,list[dict]])->dict[str,list[str]]: maps caller-name->deduplicated, order-preserving list of resolved callee names, resolving 'self.method' inside 'Class.method' to 'Class.method' and bare local names to siblings; callers with no resolved callees are omitted; {} in -> {} out. emit_module_graph(file_path, items, call_graph)->{'graph_design','metadata'}: graph_design has keys name/description/nodes/edges where name starts 'module_', each node has exactly NODE_FIELDS with type 'action', edges are [src,dst] 2-element lists augmented with 'ENTRY' and 'EXIT' sentinel nodes (empty items yields nodes [] and edges [["ENTRY","EXIT"]]); metadata has source_file (echoes file_path), generator==GENERATOR_VERSION, generated_at (str timestamp, value unconstrained), node_count, edge_count. emit_package_graph(package_dir, module_items: dict[str,list[dict]]) similarly returns name starting 'package_', metadata source_dir==package_dir, one node per module key. emit_callchain_graph(entry_name, call_graph, items_lookup, max_depth=10) BFS-walks the call graph from entry_name to max_depth, name starts 'callgraph_', metadata entry_point==entry_name. emit_full_graph(packages: dict[str,list[str]]) returns name=='full_codebase' with one node per package key. parse_shell_file(file_path)->list[dict] extracts shell function defs (type 'function', with body calls filtered of control keywords like if/then/for) and top-level UPPER_CASE variable assignments (type 'variable'); missing file -> []. walk_repo(repo_path, glob_patterns=None, exclude_dirs=None)->list[Path] returns sorted file Paths (default globs **/*.py and **/*.sh) pruning any path under an excluded dir. write_index(output_dir, graph_files)->Path creates output_dir, writes _index.json containing keys generated_at/generator(==GENERATOR_VERSION)/graphs(==graph_files verbatim), and returns the Path to that _index.json.
- `ngv2-token-logger` -> `ngv2/token_logger.py` (gate: stateful_fuzz; meta_task_type: stateful_fuzz). Exposes: PRICING, SCHEMA, _normalize_model, log_message, aggregate_session. Contract: ngv2.token_logger is a deterministic, stdlib-only (sqlite3) cost/usage ledger. It exposes PRICING: dict[str, dict[str, float]] mapping a normalized model key -> {'input','output','cache_read'} cost-per-million-tokens (USD), with at least the keys 'opus' ({'input':15.0,'output':75.0,'cache_read':1.50}) and 'sonnet' ({'input':3.0,'output':15.0,'cache_read':0.30}); SCHEMA: a single str of SQLite DDL containing CREATE TABLE IF NOT EXISTS for `messages` (columns: id PK AUTOINCREMENT, session_id, timestamp, role, model, input_tokens, output_tokens, cached_tokens, cost_usd) and `sessions` (session_id UNIQUE), plus CREATE INDEX IF NOT EXISTS statements on messages(session_id) and messages(timestamp). _normalize_model(model: str) -> str lowercases and substring-maps a raw model id to a PRICING key: 'opus' for any string containing 'opus', 'sonnet' for any string containing 'sonnet', and returns 'sonnet' for None/empty/unknown input (the deterministic default). log_message(session_id, timestamp, role, model, input_tokens, output_tokens, cached_tokens, db_path) inserts one message row (creating the schema and session row if absent), is parameterized by db_path (the injection seam — tests pass a temp sqlite file; the real default path is internal), normalizes the model before storing, computes cost_usd = round((input_tokens*PRICING[k]['input'] + output_tokens*PRICING[k]['output'] + cached_tokens*PRICING[k]['cache_read'])/1_000_000, 8), and RETURNS that float cost_usd. aggregate_session(session_id, db_path) -> dict reads back all rows for the session and returns a dict with keys total_tokens (sum of input+output+cached across messages), total_cost (rounded sum of cost_usd, round 8), and additionally total_input_tokens, total_output_tokens, total_cached_tokens, message_count; an unknown session_id returns the same dict shape with all-zero numeric values. Pure/deterministic: timestamp is caller-supplied, no clock/network/random, all I/O confined to the provided db_path.
- `ngv2-state-ledger` -> `ngv2/state_ledger.py` (gate: stateful_fuzz; meta_task_type: stateful_fuzz). Exposes: locked_read_modify_write, get_nested, set_nested, main, DEFAULT_STATE_PATH, DEFAULT_LOCK_PATH. Contract: ngv2.state_ledger is a deterministic, stdlib-only (json, fcntl, pathlib, sys) atomic JSON state ledger distilled from legacy services/state_update.py. It exposes: get_nested(d, key_path) -> Any which walks a dot-separated key path returning the value or None if any segment is missing or a non-dict is traversed (never raises); set_nested(d, key_path, value) -> None which sets a nested value creating intermediate dicts, overwriting non-dict intermediates with new dicts, and parsing value via json.loads with a fallback to the raw value on (json.JSONDecodeError, TypeError) (so set 'k' '5' stores int 5, set 'k' 'hi' stores str 'hi', non-str values pass through unparsed); locked_read_modify_write(modifier_fn, *, state_path=DEFAULT_STATE_PATH, lock_path=DEFAULT_LOCK_PATH) -> dict which, under an exclusive fcntl.flock on lock_path (creating its parent dir), reads the JSON state from state_path (treating a missing/empty file as {}), applies state = modifier_fn(state), writes it back with json.dump(..., indent=2), releases the lock, and returns the resulting state dict; and main(argv, *, state_path=DEFAULT_STATE_PATH, lock_path=DEFAULT_LOCK_PATH) -> int implementing the CLI verbs 'get key.subkey' (prints the value, exit 0), 'set key.subkey value' (locked write, exit 0), 'inc key.subkey [amount=1]' (locked int increment of current-or-0, exit 0), returning a non-zero exit code for missing/unknown verbs. DEFAULT_STATE_PATH and DEFAULT_LOCK_PATH are pathlib.Path module constants; all filesystem locations are injectable so no real orchestrator state is touched. No clock/network/random; the flock is the only external seam and is exercised against tmp paths.
