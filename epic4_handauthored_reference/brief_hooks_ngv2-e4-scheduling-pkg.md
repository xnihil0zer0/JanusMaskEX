The THREE leaves:

- `ngv2-dynamic-scheduler` -> `ngv2/dynamic_scheduler.py` (gate: pure_fuzz; meta_task_type: data_model (bypass_fuzzer, smoke-gated)). Exposes: compute_chain_roi, recommend_schedule, CHAINS, MIN_INTERVAL, MAX_INTERVAL, DEFAULT_INTERVAL, HIGH_ROI_THRESHOLD, LOW_ROI_THRESHOLD, PAUSE_THRESHOLD. Contract: ngv2.dynamic_scheduler is a PURE, deterministic, stdlib-only scheduling advisor (gate: pure_fuzz) that converts evaluation metrics in a state dict into per-chain ROI estimates and threshold-based cron-frequency recommendations. It exposes constants MIN_INTERVAL=3, MAX_INTERVAL=30, DEFAULT_INTERVAL=5, HIGH_ROI_THRESHOLD=5.0, LOW_ROI_THRESHOLD=0.5, PAUSE_THRESHOLD=0.1 (all $/hour where applicable), and a CHAINS dict whose keys (in this exact insertion order) are 'bug_hunt','mff_hunt','adversarial','mff_adversarial', each value a dict with at least keys 'metric_key' (str) and 'default_interval' (int) (defaults: bug_hunt/mff_hunt=5, adversarial/mff_adversarial=10). compute_chain_roi(state: dict) -> dict reads state['evaluation_metrics'] (dict) and state['time_tracking'] (dict) and state['adversarial'] (dict), computes op_hours = state['time_tracking'].get('operation_total_s', 0) / 3600.0, and returns a dict keyed by the four chain names; each entry is a dict with float keys 'estimated_value','hours','roi_per_hour' where hours is max(component_hours, 0.1) and roi_per_hour = estimated_value / hours. ROI estimates (deterministic, NO filesystem/clock/network): bug_hunt — submittable = evaluation_metrics.get('submittable_findings',0); estimated_value = submittable * 500 * 0.5; hours = max(op_hours*0.6, 0.1); also exposes 'findings'=submittable. mff_hunt — mff = evaluation_metrics.get('mff_findings',0); estimated_value = mff * 2000 * 0.3; hours = max(op_hours*0.3, 0.1); also 'findings'=mff. adversarial — rules = adversarial.get('rules_written',0); estimated_value = rules*100; hours = max(op_hours*0.1, 0.1); also 'rules_written'=rules. mff_adversarial is an independent copy of the adversarial entry (equal value, distinct dict object). All inputs are read defensively with .get and missing sub-dicts default to {} so an empty/partial state yields all-zero values with no exception. recommend_schedule(state: Optional[dict]=None) -> dict iterates CHAINS in order and, per chain, reads roi = compute_chain_roi(state)[chain] and roi_per_hour, then maps: roi>=HIGH_ROI_THRESHOLD -> interval=MIN_INTERVAL, action='increase_frequency'; roi>=LOW_ROI_THRESHOLD -> interval=CHAINS[chain]['default_interval'], action='maintain'; roi>=PAUSE_THRESHOLD -> interval=MAX_INTERVAL, action='reduce_frequency'; else -> interval=MAX_INTERVAL, action='consider_pause'. Each recommendation is a dict with keys 'interval_minutes' (int), 'action' (str), 'reason' (str, human-readable mentioning the ROI), 'roi' (the chain's roi dict). When state is None recommend_schedule must NOT touch the filesystem in tests; the contract requires it to default a None state to an empty dict {} (so it behaves like a zero-metric state) — i.e. recommend_schedule() == recommend_schedule({}). Functions are pure: they never mutate the caller's input dict.
- `ngv2-rate-limiter` -> `ngv2/rate_limiter.py` (gate: pure_fuzz; meta_task_type: data_model (bypass_fuzzer, smoke-gated)). Exposes: acquire, status, remaining, load_rates, save_rates, STATE_FIELDS, make_scripted_clock. Contract: ngv2/rate_limiter.py is a deterministic, stdlib-only cooldown gate for external API calls, distilled from the legacy services/rate_limiter.py. It exposes STATE_FIELDS = ('last_access', 'cooldown', 'acquired_by') naming the per-resource state dict keys. The on-disk state is a JSON object mapping resource name -> {'last_access': float, 'cooldown': float, 'acquired_by': str}. The non-determinism seam is an INJECTED clock callable `now` (a zero-arg callable returning a float epoch time), defaulting to time.time in production; the state-file location is an injected `state_path` (str or pathlib.Path), defaulting to a package-relative path. make_scripted_clock(*ticks) returns a deterministic clock that yields the given values in order (raising StopIteration-free by repeating the last value once exhausted). acquire(resource: str, cooldown_seconds: float, *, state_path, now=time.time, acquired_by='ngv2') -> bool: reads state, computes elapsed = now() - state.get(resource,{}).get('last_access', 0); if elapsed < cooldown_seconds it is RATE-LIMITED and returns False WITHOUT mutating state/file; otherwise it records {'last_access': now(), 'cooldown': cooldown_seconds, 'acquired_by': acquired_by}, persists to state_path, and returns True. A first-ever acquire (no prior record) always succeeds. remaining(resource, cooldown_seconds, *, state_path, now=time.time) -> float returns max(0.0, cooldown_seconds - (now()-last_access)); 0.0 when never acquired or fully cooled. load_rates(state_path) -> dict returns {} when the file is missing; save_rates(rates, state_path) -> None writes indent=2 JSON creating parent dirs. status(*, state_path, now=time.time) -> None pretty-prints each resource's AVAILABLE/COOLING state and returns None (no exception on empty/missing state). All functions are pure given the injected clock and path; acquire never mutates the input nor the file on the rate-limited path.
- `ngv2-model-cascade` -> `ngv2/model_cascade.py` (gate: stateful_fuzz; meta_task_type: stateful_fuzz). Exposes: ModelCascade, CASCADE_ORDER, MODEL_BACKENDS, RATE_LIMIT_PATTERNS, DEFAULT_RECOVERY_SECONDS, is_rate_limit_error, parse_recovery_time, make_default_state, get_active_model, get_backend_config, report_rate_limit, status. Contract: ngv2.model_cascade is a deterministic, stdlib-only model-fallback state machine over an INJECTED clock seam (never the real wall clock, disk, network, or randomness). It cascades across model rate-limit boundaries in fixed order CASCADE_ORDER=['sonnet','opus','codex','gemini']. MODEL_BACKENDS maps model->(backend, model_name): 'sonnet'->('claude','sonnet'), 'opus'->('claude','opus'), 'codex'->('codex',None), 'gemini'->('gemini',None). RATE_LIMIT_PATTERNS is a list of lowercase substrings and is_rate_limit_error(text)->bool returns True iff any pattern is a substring of text.lower(). parse_recovery_time(text)->float extracts a retry-after duration from 'retry after N seconds/minutes' or 'try again in N seconds/minutes' (minutes*60), defaulting to DEFAULT_RECOVERY_SECONDS=300.0 (a float). make_default_state()->dict returns a fresh {'active_model':'sonnet','cascade':CASCADE_ORDER,'limits':{m:{'hit_at':None,'recovery_at':None,'error':None}},'last_updated':None}. Core engine class ModelCascade(state=None, clock=time.time): clock is a zero-arg callable returning float now; instance owns its own state dict (make_default_state() default). get_active_model()->str returns active model but FIRST switches back to any earlier/more-preferred model whose recovery_at is set and <= now, clearing that model's limit. report_rate_limit(model, error_text='', recovery_seconds=DEFAULT_RECOVERY_SECONDS)->str records limits[model]={'hit_at':now,'recovery_at':now+recovery_seconds,'error':error_text[:500] or None}, then advances active_model to the next not-currently-limited model after `model` in CASCADE_ORDER; if all later models limited, falls back to the model with the soonest recovery_at among all (clearing its limit); returns new active model. get_backend_config()->tuple[str,Optional[str]] returns MODEL_BACKENDS for the active model (default ('claude','sonnet')). status()->dict={'active_model','cascade','models':{m:{'status':'rate_limited','recovery_in_seconds':round(remaining,1),'error':str} if recovery_at and now<recovery_at else {'status':'available'}}}. last_updated set to an ISO-8601 string on mutation. Module-level get_active_model/get_backend_config/report_rate_limit/status delegate to a process default singleton; reset_cascade(clock=time.time)->ModelCascade replaces and returns a fresh deterministic singleton so the module-level API is testable with an injected clock. Fully in-memory and pure given the injected clock.
