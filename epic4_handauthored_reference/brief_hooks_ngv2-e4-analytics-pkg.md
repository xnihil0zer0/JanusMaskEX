Contract: ngv2.hunting_roi_tracker is a pure, stdlib-only deterministic session-ROI tracker that decides when a hunting run should stop hunting and switch to PoC work. It exposes module constants SESSION_FILE (a pathlib.Path default JSON session location), DEFAULT_THRESHOLD = 2 (findings-per-hour), and WARMUP_HOURS = 0.5. All time access is via an INJECTED zero-arg `clock` callable (defaults to time.time) so ROI math is fully deterministic in tests; all file access is via an INJECTED `session_path` keyword (defaults to SESSION_FILE). load_session(session_path=SESSION_FILE) returns the persisted session dict or None when the file is missing or corrupt (never raises on bad JSON). save_session(session, session_path=SESSION_FILE) writes the session dict as pretty JSON, creating parent dirs. start_session(session_path=SESSION_FILE, clock=time.time) creates+persists and RETURNS a fresh session dict with keys {'start_epoch': float, 'findings': [], 'findings_count': 0}, resetting any prior session. record_finding(description, severity='medium', session_path=SESSION_FILE, clock=time.time) loads (auto-starting if none exists), appends a finding dict {'description', 'severity'} (severity lowercased), updates findings_count, persists, and RETURNS a dict {'findings_count': int, 'description': str, 'severity': str}. check_roi(threshold=DEFAULT_THRESHOLD, session_path=SESSION_FILE, clock=time.time) returns a dict with keys {'recommendation' in ('keep_hunting','switch_to_poc'), 'findings_count': int, 'findings_per_hour': float, 'elapsed_hours': float, 'threshold': (the threshold used), 'severity_breakdown': dict[severity->count]}; when no session exists it returns recommendation 'keep_hunting' with findings_count 0 and elapsed_hours 0.0. Recommendation logic: during the warmup window (elapsed_hours < WARMUP_HOURS) always 'keep_hunting'; after warmup, 'switch_to_poc' iff findings_per_hour < threshold, else 'keep_hunting'. findings_per_hour = findings_count / elapsed_hours (0.0 when elapsed is 0). The module is pure (no global mutable state beyond the file), deterministic, and never performs network/LLM/subprocess calls.
