The FOUR leaves:

- `ngv2-ast-constraint` -> `ngv2/ast_constraint.py` (gate: pure_fuzz; meta_task_type: data_model (bypass_fuzzer, smoke-gated)). Exposes: check_code_string, check_file, format_violations, ASTConstraint, VIOLATION_FIELDS, MAX_CODE_CHARS. Contract: ngv2.ast_constraint is a pure, stdlib-only (ast module) code-safety gate that scans Python source strings for dangerous/sloppy patterns and returns a deterministic list of violation dicts. It exposes: VIOLATION_FIELDS = ('rule','line','description','severity') (the exact ordered keys of every violation dict); MAX_CODE_CHARS = 50000 (perf guard — strings longer than this are skipped and return []). check_code_string(code: str) -> list[dict] returns [] for clean/empty/None/non-str/oversized input; on a SyntaxError it returns exactly one violation dict {rule:'syntax_error', line:<int e.lineno or 0>, severity:'error', ...} and performs no further analysis. When the source parses, it walks the AST and emits one violation dict per occurrence with these stable rule names/severities: 'bare_except_pass' (severity 'error', for `except: pass` / empty body), 'except_exception_pass' (severity 'error', for `except Exception:`/`except BaseException:` with empty body — an empty body is a body of only ast.Pass and/or string-constant docstring exprs; narrow named excepts like ValueError are NOT flagged), 'os_system_call' (severity 'warning', for os.system(...)), 'subprocess_no_check' (severity 'warning', for subprocess.run(...) lacking both check= and capture_output= kwargs), and 'dev_null_stderr' (severity 'warning', for a string literal containing '2>/dev/null'). Each violation dict has exactly the keys rule(str), line(int, 1-based lineno of the offending node, 0 if unknown), description(non-empty str), severity(str, either 'error' or 'warning'). check_file(file_path: Path) -> list[dict] returns [{rule:'file_not_found',severity:'error',...}] for a missing path, otherwise reads UTF-8 text and delegates to check_code_string. format_violations(violations, verbose=False) -> str returns the literal string 'No violations found.' for an empty list, otherwise a newline-joined human-readable summary that mentions each violation's severity (upper-cased), line, and rule. class ASTConstraint is a stateless OO facade with methods check(code)->list[dict] (==check_code_string), check_file(path)->list[dict], is_clean(code)->bool (True iff no violations), has_error_violations(code)->bool (True iff any violation has severity=='error'). Pure/deterministic: no clock, network, randomness, or filesystem writes; same input always yields the same output.
- `ngv2-ast-verifier` -> `ngv2/ast_verifier.py` (gate: pure_fuzz; meta_task_type: data_model (bypass_fuzzer, smoke-gated)). Exposes: Violation, ASTResult, ASTVerifier. Contract: ngv2/ast_verifier.py is a pure, stdlib-only (ast module) symbolic policy verifier for Python source — no network/LLM/subprocess/randomness. It exports two dataclasses and one class. @dataclass Violation has fields rule: str, line: int, message: str, severity: str (one of the string literals 'ERROR' | 'WARNING'). @dataclass ASTResult has fields valid: bool and violations: list[Violation] (default_factory=list), plus methods has_errors() -> bool (True iff any violation has severity=='ERROR'), has_warnings() -> bool (True iff any violation has severity=='WARNING'), and summary() -> str returning 'OK (no violations)' when there are no violations else exactly 'N error(s), M warning(s)' with N=count of ERROR and M=count of WARNING violations. class ASTVerifier exposes verify(code: str, filename: str = '<string>') -> ASTResult and verify_file(path: str) -> ASTResult. verify parses code with ast.parse; on SyntaxError it returns ASTResult(valid=False, violations=[Violation(rule='syntax', line=<e.lineno or 0>, message starting with 'SyntaxError:', severity='ERROR')]) and performs no further checks. On a parseable tree it walks the AST applying these rules: rule='bare_except' ERROR when a bare `except:` (ExceptHandler with type is None) has a body that is exactly a single `pass`; rule='os_system' ERROR for any os.system(...) call (Attribute attr=='system' on Name 'os'); rule='subprocess_no_check' ERROR for subprocess.run/call calls lacking check=True and not having their return value's .returncode referenced (subprocess.Popen, check_call, check_output are exempt); rule='devnull_no_comment' WARNING (a line-based text scan) when a line contains the literal '2>/dev/null' and neither that line nor the immediately adjacent (prev/next) line contains a '#'. valid is True iff no ERROR-severity violation is present (WARNINGS alone keep valid True). Each Violation.line is 1-based. verify_file reads the file (utf-8, errors='replace') and delegates to verify(code, filename=path); on OSError it returns ASTResult(valid=False, violations=[Violation(rule='file_read', line=0, severity='ERROR', message starting with 'Cannot read file')]).
- `ngv2-backtrack` -> `ngv2/backtrack.py` (gate: stateful_fuzz; meta_task_type: stateful_fuzz). Exposes: BacktrackError, BacktrackContext, make_mock_verifier, make_scripted_verifier, BACKTRACK_TOKEN_FIELDS, DEFAULT_CONSTRAINT_SET. Contract: ngv2.backtrack is a deterministic, stdlib-only stateful retry shell for symbolic code validation driven by an injected verification seam. See exported_symbols and oracle for the exact surface: BacktrackError(violations, attempt) with .as_constraint(); BacktrackContext(max_retries, ast_verifier, z3_bridge, constraint_set) as a context manager with validate/get_negative_constraints/emit_backtrack_token and attempt/backtrack_count/gave_up; pure deterministic token (no clock/file IO); plus make_mock_verifier/make_scripted_verifier seam factories and BACKTRACK_TOKEN_FIELDS/DEFAULT_CONSTRAINT_SET constants.
- `ngv2-z3-bridge` -> `ngv2/z3_bridge.py` (gate: injected_seam; meta_task_type: data_model (bypass_fuzzer, smoke-gated; injected mock seam)). Exposes: Z3Result, Z3Bridge, _CONFIDENCE_RANK, CONSTRAINT_SETS, make_mock_solver, make_scripted_solver. Contract: ngv2.z3_bridge is an injected-seam neurosymbolic invariant checker: a PURE deterministic shell plus an OPTIONAL injected solver callable so the factory never imports real z3. It exports a frozen @dataclass Z3Result(satisfied: bool, reason: str, z3_used: bool, elapsed_ms: float = 0.0) whose __bool__ returns self.satisfied. Constant _CONFIDENCE_RANK == {'LOW':0,'MEDIUM':1,'HIGH':2,'CONFIRMED':3} (exact keys/values). Constant CONSTRAINT_SETS == ('grounding','gate') (the recognized named constraint sets). class Z3Bridge(solver_fn=None): if solver_fn is None the bridge uses the built-in deterministic rule-based path (Z3Result.z3_used=False); if a solver_fn callable is injected it is invoked as solver_fn(constraint_set, state) -> bool and the bridge wraps the bool into a Z3Result with z3_used=True (the injected seam, NEVER a real solver). check_invariants(constraint_set: str, state: dict) -> Z3Result: constraint_set is matched case-insensitively after .lower().strip(); for 'grounding' the invariant is (codeql_found or joern_found) implies _CONFIDENCE_RANK[confidence] >= _CONFIDENCE_RANK['HIGH'] where state confidence is upper/stripped and unknown confidence ranks -1 (vacuously satisfied when no taint found); for 'gate' the invariant is (submitting and live_test_required) implies live_test_passed with live_test_required defaulting True and submitting/live_test_passed defaulting False; an UNKNOWN constraint_set returns satisfied=True (no constraints, z3_used=False). verify_harness_edit(edit_diff: str) -> Z3Result is a pure static diff scanner examining ONLY added lines (those starting with '+', after stripping the '+'), flagging as violations: '|| true' without a '#' comment, '2>/dev/null' without a '#' comment, and a line containing 'confidence' (case-insensitive) that lowers it to a quoted LOW or MEDIUM; satisfied=False with all violations joined in reason when any found, else satisfied=True. All methods return within a few ms; elapsed_ms is a non-negative float and is never asserted to an exact value. Factories make_mock_solver(verdict: bool) and make_scripted_solver(mapping: dict[str, bool], default: bool = True) build injectable solver_fn callables: the mock always returns verdict; the scripted returns mapping.get(constraint_set.lower().strip(), default). stdlib only.
